# GTM Command Center

The front door for a connected set of RevOps / GTM tools. Live: https://gtm-command-center-phi.vercel.app

A single self-contained landing page (`index.html`, no framework) linking to:

- **Lead Routing Engine** — scores, matches, and routes inbound leads. https://lead-routing-engine.vercel.app
- **Deal Trajectory Engine** — scores open pipeline for stall risk. https://deal-trajectory-engine.vercel.app

Each tool also carries a shared top bar to switch between them. Pushes to this repo auto-deploy to Vercel.
